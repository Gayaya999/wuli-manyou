# 物理漫游｜38 秒宣传动画制作资料

本目录用于制作一支新的《苹果之外》宣传动画，包含已确认的文字脚本、两个参考视频，以及便于查看的带时间码关键帧概览。它与仓库现有的 `experiences/apple-beyond/` 互动影片是独立的制作任务。

## 从这里开始

1. 阅读 [38 秒动画脚本](./script.zh-CN.md)，以其中的 10 段时间轴为叙事依据。
2. 查看参考一的视频与关键帧，理解物件替换、快速切换、缩放和停顿的节奏。
3. 查看参考二的视频与关键帧，理解“提出问题 → 改变方式 → 展示行动 → 展开愿景”的叙事。
4. 检查项目当前素材和交互，再制定制作方案。脚本中的插盘、纸张折叠及画面衔接属于拟制作的影片包装，不代表网站已有这些动效。

关键帧概览是从参考文件中抽帧生成的静态图片，可辅助观察构图与段落；判断准确节奏、转场和声音时仍应查看视频。

## 可直接交给 Claude 的任务

```text
请基于这个仓库制作“物理漫游”的一支 38 秒宣传动画。

先阅读 docs/video-production/wuli-manyou-promo-38s/script.zh-CN.md，再查看同目录 references/ 下的两个视频和两张带时间码关键帧概览，并检查项目当前页面、素材与牛顿实验内容。

创作要求：
1. 以脚本的 10 段时间轴为基础，总长 38 秒，成片必须小于 40 秒。
2. 1920×1080，16:9，30fps；38 秒对应 1140 帧。
3. 无配音、无人物对白、无歌词人声；只使用音乐和动作音效。画面保留少量必要公式、操作标签及片尾“物理漫游 / Press start”，不用长字幕讲解。
4. 参考一借鉴快速切换、物件替换、突然缩放与停顿；参考二借鉴提出问题、改变方式、展示行动、展开愿景的结构。使用项目自己的视觉语言和素材，重新设计转场与声音。
5. 核心叙事是从纸上的苹果进入科学家软盘和复古电脑，亲手完成引力实验，理解苹果与月亮的联系，最后展开九位科学家的世界。
6. 优先复用 assets/disks/、assets/guides/、assets/hardware/、assets/relics/、assets/bg/ 中的素材，并检查 published-modules/newton-gravity/game-pack/experience.json 中的实验内容。
7. 距离实验保持其他条件不变，中心距离加倍时，引力变为原来的四分之一。轨道镜头始终保留朝向星球的引力关系。
8. 其他科学家的镜头作为知识世界预告，不把未核实的功能表现成已经可玩的完整游戏。
9. 优先做好“纸张折成软盘”“推入电脑屏幕”“发射轨迹接成月球轨道”三个关键转场。
10. 建立独立的制作目录，与现有 experiences/apple-beyond/ 影片分开；保留现有网站功能。

请先说明你实际读取到的资料与当前环境具备的制作、预览、渲染能力。如果无法直接查看 MP4，请使用关键帧概览理解视觉，并明确视频声音与精确节奏仍需核对，不要声称已看完视频。

随后给出可执行的制作安排并实施，交付动画源文件、可预览结果与导出方式；若环境支持视频渲染，导出 MP4。若某一步受环境限制，明确已完成内容及所需的后续操作，不要将未渲染的源文件称为成片。
```
